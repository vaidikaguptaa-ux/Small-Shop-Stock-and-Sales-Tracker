# Small-Shop-Stock-and-Sales-Tracker

Project Overview

This is a beginner-friendly Python project designed to help a small shop manage its inventory and record sales.

Features

* Display product names, prices, and available stock.
* Record product sales.
* Validate product names and quantities.
* Prevent selling more items than are available.
* Calculate and display total sales.
* Save and reload product and sales information using JSON.

Technologies Used

* Python
* Dictionaries and nested dictionaries
* Loops and conditional statements
* Numeric calculations
* File handling and JSON

How to Run

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Run the cell that defines the products.
3. Run the main menu cell.
4. Select an option from the menu to use the tracker.

Project Objective

The objective of this project is to practise Python fundamentals by building a simple inventory and sales management system.
